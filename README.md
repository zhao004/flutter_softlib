A Flutter-based software library app for browsing categorized apps, searching resources, reading tips/articles, and
managing downloads.

一个基于 Flutter 的软件库应用，支持软件分类浏览、资源搜索、线报/文章阅读和下载管理。

![Flutter SoftLib preview](assets/images/example/app_example.png)

## Project Snapshot / 项目速览

- Open-source learning project focused on Flutter app architecture and Android packaging workflow.
- Features include home carousel, announcements, official recommendations, categorized app library, search, article
  reading, download management, and update prompts.
- Windows users can use `build.bat` for guided configuration and APK packaging.
- Full documentation is available in `README.zh-CN.md` and `README.en.md`.
